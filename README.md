# مختبر الفحص المسماري ثلاثي الأبعاد | Cuneiform RTI 3D Studio

منصة تفاعلية متطورة لفحص وقراءة الألواح والنصوص المسمارية بتقنيات المتاحف العالمية (RTI - Reflectance Transformation Imaging) والضوء المائل الكاشف (Raking Light) مع قارئ نصوص مريح للعينين ودعم كامل لمجسمات GLB ثلاثية الأبعاد.

---

## 🚀 التشغيل السريع محلياً

افتح الطرفية (Terminal) في مجلد المشروع ونفذ:

```bash
./start.sh
# أو
npm run dev
```

ثم افتح المتصفح على الرابط:
**[http://localhost:5173/](http://localhost:5173/)**

---

## 📦 مجلد ملفات المجسمات ثلاثية الأبعاد (GLB Models)

تم تخصيص مجلد جاهز لاستقبال ملفاتك:
📁 **`public/models/`** (أو الاختصار **`models/`**)

- ضع أي ملف بصيغة `.glb` أو `.gltf` داخل هذا المجلد.
- يمكنك أيضاً سحب وإفلات أي ملف `.glb` مباشرة فوق نافذة الموقع وسيقوم المتصفح بعرضه فوراً وتطبيق إضاءة وظلال الفحص الأثري عليه!
- أو الضغط على زر **"📦 استيراد ملف GLB"** في أعلى الموقع أو في اللوحة الجانبية.

---

## 🌐 الرفع على GitHub وتشغيله كـ GitHub Pages فوراً

المشروع مُعد ومُهيأ بالكامل ليعمل مباشرة بدون أي تعديل إضافي:

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub.
2. ارفع الملفات إلى المستودع:
   ```bash
   git init
   git add .
   git commit -m "Initial Cuneiform 3D Studio"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```
3. تم تضمين ملف **GitHub Actions** تلقائي في المسار `.github/workflows/deploy.yml`:
   - سيقوم GitHub ببناء الموقع ونشره تلقائياً بمجرد الرفع!
   - لتفعيل الرابط، اذهب إلى إعدادات المستودع: **Settings -> Pages** واختر Source: **GitHub Actions** (أو اختر Deploy from branch: `main` / `docs`).
   - سيعمل الموقع مباشرة على رابط: `https://USERNAME.github.io/REPO_NAME/`

## ✨ أبرز الميزات المضمنة
1. **قبة الإضاءة التفاعلية (Virtual Dome)** لتحريك زاوية الضوء والظلال 360° في الوقت الفعلي.
2. **شادر الضوء المائل الكاشف (Raking Light)** لفك رموز المسامير المتآكلة.
3. **قارئ نصوص مريح جداً للعينين** بنصوص مسمارية تاريخية، ترجمة عربية فصيحة، ونقح صوتي أكدي.
4. **تقليب اللوح 360°** وأزرار سريعة للوجه الأول والقفا والحواف.
5. **تصدير لقطات فائقة الدقة (Snapshot)** وتصدير المجسم كملف GLB.
